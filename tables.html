Table QR cards

A6 table tents, four to an A4 sheet. Each code opens the menu with its table number.

Finish

Putting these on tables

  1. Host the folder anywhere public (Netlify, Vercel, GitHub Pages, your own website) and paste that address above. The QR codes update instantly.
  2. Scan one card with your phone before printing the batch — check it opens the right table.
  3. Print on 300–350 gsm matte card at 100% scale (no "fit to page"), then cut along the card edges.
  4. Slide each card into an acrylic A6 stand. Keep the code at least 4 cm wide so older phones read it from a seated position.
  5. The menu itself lives in menu-data.js. Change a price there and every table updates — no reprinting.
